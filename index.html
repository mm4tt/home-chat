Home Chat

A private, secure Google Chat bot bridging messaging with home automation infrastructure.

About the Application

Home Chat is a dedicated assistant that allows family members to interact with private home automation services directly from Google Chat.

It processes incoming chat commands in real time, routes requests to private local infrastructure, and provides synchronous status updates and event notifications.

Home Control

Trigger and manage smart home actions and routines from within Google Chat.

End-to-End Privacy

Zero third-party analytics or external trackers. Data is processed strictly for command execution.

Strict Authorization

Commands are restricted to verified household members via user allowlists.
